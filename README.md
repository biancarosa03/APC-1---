# PPC 1 - Cálculo Numérico

Implementação computacional do método de Runge-Kutta
de quarta ordem (RK4) aplicado ao problema de sedimentação
de uma partícula esférica.

## Método utilizado

Foi implementado manualmente o método de Runge-Kutta
de quarta ordem para resolver a equação diferencial
adimensional do problema.

## Análises realizadas

1. Comparação entre a solução numérica e a solução analítica
   para diferentes números de Stokes;

2. Influência do passo de tempo h;

3. Efeito inercial para Re_s diferente de zero;

4. Validação da solução numérica para diferentes valores
   de Re_s;

5. Influência do número de Reynolds da partícula.
